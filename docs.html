Pipeline

Luau source
  → Custom Register-Based VM (130 opcodes, random map / build)
  → bytecode + interpreter (Lua)
  → Complex State Machine IR
  → Triple multi-frag encode (XOR→hex→Base94)
  → Junk + Anti-Tamper + loadstring

Full Luau path

  • Lexer + Parser → AST
  • Scramble locals/functions → __n1…
  • AST → bytecode khi đủ subset; không thì EXECSTR source đã scramble
  • VM 130 op + SM + triple pack

Custom VM

  • 130 opcode slots — map vật lý random mỗi lần Obfuscate
  • Bảng handler XOR-mask — dump thấy số junk
  • Subset compile (assign/call/binop) → bytecode thật
  • Script phức tạp → EXECSTR qua VM (source trong constant pool)

Pipeline (pack)

Luau source
  → Custom Register VM (~130 op) + State Machine IR
  → Multi-fragment triple encode (XOR→hex→XOR→Base94 × 3 × 5–7 pieces)
  → Junk 120–150KB + Anti-Tamper
  → loadstring loader

State Machine

  • Full Luau: không tách statement — toàn bộ script trong 1 block thật → mọi syntax hợp lệ đều chạy.
  • Entry chain: 4–8 hops junk trước body.
  • Triple opaque: 3 họ predicate lồng bọc body.
  • Dead / mid states: 12–21+ state nhiễu + phase counter.
  • Virtual table __VT: hằng số giả dispatch.

Dump vẫn thấy logic (chưa phải VM/AST rename). Muốn source sạch phải phân tích / viết lại một phần.

API (Netlify Function)

Sau khi deploy, endpoint:

POST /api/obfuscate
Content-Type: application/json

{ "code": "print(\\"ok\\")" }

Response:

{
  "ok": true,
  "code": "return(function()...end)()",
  "meta": { "inputBytes": 12, "outputBytes": 140000, "fragments": 5 }
}
curl -s -X POST https://YOUR_SITE.netlify.app/api/obfuscate \\
  -H "Content-Type: application/json" \\
  -d '{"code":"print(\\"2\\")"}'

Deploy Netlify

  1. Kéo thư mục 8xms-web lên Netlify (hoặc connect Git).
  2. Build: để trống / Publish: .
  3. Functions tự nhận netlify/functions.

Giới hạn

  • Không phải Luraph VM — reverse vẫn được nếu chịu khó.
  • Long string [[...]] không đưa vào string pool (tránh vỡ).
  • API function chạy cùng logic JS (Node 18+).
